# AITradeBot V2

## Overview

AITradeBot V2 is a professional, event-driven algorithmic trading platform built in Python.

The goal of this project is to create a modular, scalable, and broker-independent trading engine that supports:

- Live Trading
- Replay Mode
- Backtesting
- Multiple Trading Strategies
- AI-assisted Trade Analytics

---

## Design Principles

- Clean Architecture
- Event-Driven Design
- SOLID Principles
- Replay = Live
- Strategy Independent
- Broker Independent
- Configuration over Code
